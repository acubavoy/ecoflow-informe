
# EcoFlow DELTA Max (2000) - Informe Técnico y Comercial

Este repositorio contiene un informe completo en HTML sobre la estación de energía portátil **EcoFlow DELTA Max (Modelo EFD310)**.

## 📄 Contenido del informe

- Benchmark de precios (actualizado a julio 2025)
- Imágenes del equipo y enlaces a distribuidores confiables
- Diseño optimizado para móviles (relación 9:16)
